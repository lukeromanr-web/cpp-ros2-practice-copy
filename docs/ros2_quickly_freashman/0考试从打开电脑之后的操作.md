## 一、现在怎么打开 VSCode 开始练习？

你之前已经成功连接过 WSL，截图左下角显示 `WSL: Ubuntu-22.04`，所以不用重新配置连接。

### 第一步：打开 Ubuntu 终端，输入

```
cd ~/ros2_exam_ws
code .
```

注意最后的 `.`，代表打开当前整个工作空间，而不是只打开一个文件。

### 第二步：在 VSCode 左侧找到文件

ros2_exam_ws

src

robot_speed_pkg

CMakeLists.txt

src

speed_monitor.cpp

点击 `speed_monitor.cpp` 就能直接修改你刚才写好的程序。

## 二、考试时完整操作链条

这是你真正需要熟悉的流程：

| 顺序  | 操作                          | 是否每次需要       |
| --- | --------------------------- | ------------ |
| ①   | 启动 Ubuntu/WSL、VSCode        | 每次考试或练习      |
| ②   | 打开 ROS2 工作空间 `code .`       | 每次打开项目       |
| ③   | 加载 ROS2 环境 `source`         | 每个新终端，除非自动加载 |
| ④   | 创建功能包                       | 新项目才需要       |
| ⑤   | 编写 `.cpp`、修改 CMakeLists     | 按题目需要        |
| ⑥   | `colcon build`              | 修改 C++ 代码后   |
| ⑦   | `source install/setup.bash` | 新终端或首次安装后    |
| ⑧   | `ros2 run`                  | 每次启动程序       |

## 三、以后可以直接在 VSCode 内完成所有操作

不需要在 Ubuntu 黑色窗口和 VSCode 之间来回切换。

在 VSCode 中按：

`Ctrl + Shift + 反引号` 可以新建终端，也可以从菜单 终端 → 新建终端 打开。

确认左下角是 `WSL: Ubuntu-22.04`，终端运行：

```
source /opt/ros/humble/setup.bash
cd ~/ros2_exam_ws
source install/setup.bash
```

之后你就可以：

上方编辑 C++ → Ctrl+S 保存 → 下方终端编译运行。

```
colcon build --packages-select robot_speed_pkg
source install/setup.bash
ros2 run robot_speed_pkg speed_monitor
```

## 四、考试真的需要配置环境吗？

要分清楚两类配置：

- 系统级配置： 安装 Ubuntu、ROS2、VSCode、colcon。通常是考前准备，但要看考场是否提供环境。
    
- 项目级配置： 建工作空间、创建功能包、配置 CMake、编译和运行。这些很可能属于现场编程的基本操作。
    

一句话判定：你现在需要练习的不是重新安装 ROS2，而是能不看指导独立完成「打开工作空间 → 修改程序 → 编译 → 运行」。

下一步建议你在 VSCode 中打开整个 `ros2_exam_ws`，以后 ROS2 + vector 的三面练习都放在这个工作空间里进行。
