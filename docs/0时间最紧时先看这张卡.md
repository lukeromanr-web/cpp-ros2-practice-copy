# 考场速查卡

**ROS2 不能直接照抄 ROS1 命令：** `catkin_make` → `colcon build`；`rosrun` → `ros2 run`；`roscpp` → `rclcpp`。

## 程序切入点

发布：timer → `std_msgs::msg::Int32 message` → `message.data = speed` → `publisher_->publish(message)`。

接收：`on_speed(const std_msgs::msg::Int32 &msg)` → `int speed = msg.data` → `queue.push(speed)`。

处理：队列 `size() >= 2` → `front()` → `absoluteDifference()` → `vector.push_back(diff)` → 超过 4 个 `erase(begin())` → 遍历计数 `>= 3` → `UNSTABLE` 当计数 `>= 2` → 更新 previous → `pop()` 删除处理完的队头。

## 文件职责

- `.cpp`：节点运行逻辑（主体）。
- `package.xml`：依赖声明。
- `CMakeLists.txt`：声明可执行文件、链接依赖及安装规则。
- 终端：`source /opt/ros/版本/setup.bash` → `colcon build` → `source install/setup.bash` → `ros2 run 包名 可执行名`。

## 5 个不能错的地方

1. 不能把 `message` 和 `message.data` 当成同一个对象。
2. Publisher 与 Subscriber 的消息类型和 topic 必须匹配。
3. queue 是 **front + pop**，不是 vector 的下标。
4. vector 超过 4 条就删最早数据；判断是 `>=3`，不是 `>3`。
5. previous 只在处理完成后更新，不是每次收到消息就更新。
